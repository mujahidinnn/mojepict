📐 Spacing Scale

Use ONLY these values. No custom spacing.

Token Value Tailwind Class Usage

md 1.5rem (24px) gap-4 Section separation, padding
lg 2rem (32px) gap-6 Major layout gaps
xl 2.5rem (40px) gap-8 Top-level sections

🎯 Layout Patterns

Two-Column (Input | Output)

For converters, image processors, calculators with split views.

<TwoColumnLayout>
  <InputSection label="Input">
    <Textarea className="min-h-96 p-4 resize-none" />
  </InputSection>

  <OutputSection label="Output">
    <ResultCard label="Name" content={result} onCopy={copy} />
  </OutputSection>
</TwoColumnLayout>

Single-Column (Full Width)

For generators, calculators, small tools.

<div className="max-w-screen-lg flex flex-col gap-8">
  <div className="space-y-4">
    <Label>Setting</Label>
    <Slider />
  </div>
</div>

Result Card (Copy-able Output)

<ResultCard
  label="Converter Name"
  content={result}
  onCopy={copyResult}
  disabled={!result}
/>

✅ Do's & Don'ts

Use spacing scale exclusively:
  • gap-3, gap-4, gap-6
  • space-y-3, space-y-4
  • p-4, p-6
Avoid custom spacing:
  • gap-1, gap-5, gap-7
  • p-2, p-3, p-7
  • mt-, mb-, ml-, mr-
Use Tailwind's semantic colors:
  • text-primary
  • bg-muted/10
  • text-muted-foreground
Avoid hardcoded colors:
  • dark:text-red-500
  • bg-blue-600
  • text-[#ff0000]

📝 Refactoring Checklist

For each component being standardized:

  • ☐ Identify: two-column or single-column layout
  • ☐ Replace layout divs with templates
  • ☐ Fix spacing: remove custom gaps, use scale only
  • ☐ Textarea: min-h-96 p-4 resize-none
  • ☐ Labels: text-xs font-semibold text-muted-foreground
  • ☐ Cards: p-6 and use ResultCard
  • ☐ Buttons: h-9 w-9 for icons, h-8 px-2 for compact
  • ☐ Max-width: max-w-screen-lg (no custom widths)
  • ☐ Test responsive (mobile, tablet, desktop)
